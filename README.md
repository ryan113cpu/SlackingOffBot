# Slacking_Parrot!!!!!

Slacking_Parrot is a fun! cohesive Slack application built using Node.js and the @slack/bolt framework. It is securely configured using Socket Mode and is deployed 24/7 on the Hack Club Nest server environment.

# Why I Maked This Bot

I wanted to build a personalized, themed assistant that brings humor into a developer's daily workflow. The theme centers around a mischievous parrot that helps engineers find excuses to slack off, create fake availability statuses to handle heavy workloads, or deploy emergency alerts to escape long, unproductive meetings.

# Commands and Features 

use these commands directly in slack  
/parrot_nap' - Generates a random, believable technical excuse explaining why you are suddenly AFK or offline.
/parrot_coffee' - Recommends a fake busy status template (e.g., "Deep Work," "Investigating Outage") to clear up your schedule.
/parrot_fakeout' - Dispatches an emergency system alert message template so you can cleanly drop out of a live meeting.

# How to Run Locally

1. Clone this repository to your laptop.
2. Run 'npm install' to download dependencies.
3. Configure your local '.env' file with 'SLACK_BOT_TOKEN' and 'SLACK_BOT_TOKEN'.
4. Launch the application process using 'node bot.js'
